# 附录 · 接口清单（35 个）

> 全部为 `POST/GET /api/*`，JSON 进出，纯 Python 标准库实现，无框架。
> 认证：Cookie 会话（`sid`），12 h 过期。角色：`admin` 全量 / `editor` 除回滚、增删、账号、清理外全量。

## 一、认证与状态

| 方法 | 路径 | 作用 | 权限 | 备注 |
|---|---|---|---|---|
| POST | `/api/login` | 登录 | 匿名 | 失败计数，锁定 5 分钟 |
| POST | `/api/logout` | 登出（踢本会话） | 登录 | — |
| POST | `/api/password` | 改密 | 登录 | 改完踢全部会话 |
| GET | `/api/status` | 系统状态（rev / 保存时间 / 发布状态 / 角色） | 登录 | 后台首屏调用 |

## 二、内容读写

| 方法 | 路径 | 作用 | 权限 |
|---|---|---|---|
| GET | `/api/content` | 读全量内容 + rev | 登录 |
| POST | `/api/content` | 保存（带 rev 乐观锁，冲突 409） | 登录 |
| POST | `/api/preview` | 生成整站预览到 `_preview/` | 登录 |
| GET | `/api/search?q=` | 全字段搜索，返回页面/字段/片段 | 登录 |
| POST | `/api/replace` | 批量替换（先预览命中数，执行前备份） | 登录 |

**`POST /api/content` 契约**：

```json
// 请求
{"content": {...}, "rev": 52, "force": false}
// 成功
{"ok": true, "rev": 53, "saved_at": "16:02:11", "changed": 3}
// 冲突
{"ok": false, "error": "有更新的修改", "rev": 53, "diff": [{"path":"home_service.hero_title","old":"…","new":"…"}]}
```

```json
  "built": [{"page": "index.html", "ms": 12, "ok": true}],
  "errors": [],

  "elapsed": 0.2, "ok": null, "rolled_back": false

```

## 十一、错误码约定

| 码 | 含义 | 前端行为 |
|---|---|---|
| 200 | 成功 | — |
| 400 | 参数不合法 | 提示具体字段 |
| 401 | 未登录 / 会话过期 | 跳登录，保留 localStorage 草稿 |
| 403 | 权限不足 | 提示需要什么角色 |
| 404 | 资源不存在 | — |
| 409 | 冲突（rev / 发布互斥 / 图片被引用 / 锁超时） | 弹窗说明 + 给出解决方案 |
| 500 | 服务端异常 | 显示人话 + 「看详细日志」 |
